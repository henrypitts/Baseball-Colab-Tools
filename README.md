
# Baseball Analytics Tools

A collection of Python-based tools and notebooks I've developed and used over time to support baseball analytics, player evaluation, scouting, and player development.

These tools reflect different approaches to working with baseball data, including statistical analysis, data visualization, player comparisons, and performance evaluation.

## Notebooks

### 1. Arm Angle Search
**File:** `Arm_Angle_Search.ipynb`

A tool for exploring pitcher arm angles and identifying relationships between release characteristics, pitch movement, and performance.

- Analyze pitchers by arm angle
- Compare pitch characteristics across different arm slots
- Identify pitchers with similar release profiles
- Explore relationships between arm angle and pitch effectiveness

### 2. Blast Motion Analysis
**File:** `Blast_Motion_Analysis.ipynb`

A player development tool designed to analyze swing characteristics using Blast Motion sensor data.

- Evaluate swing plane and on-plane efficiency
- Analyze attack angle and connection metrics
- Identify trends and areas for mechanical improvement
- Visualize live player performance

### 3. Minor League Pitcher Search
**File:** `MilLB_Search.ipynb`

A tool for researching and comparing minor league pitchers using statistical and pitch-level data.

- Search and filter minor league pitchers
- Compare pitching performance and characteristics
- Support prospect research and scouting

### 4. Pitcher Reports
**File:** `Pitchers_Report.ipynb`

A tool for generating pitcher evaluations and examining pitch arsenals, tendencies, and performance from YakkerTech Files.

- Analyze pitch usage and arsenal composition
- Evaluate velocity, spin, and movement characteristics
- Examine pitch effectiveness
- Visualize pitching profiles
- Support individual pitcher scouting and evaluation

## Technologies

- **Language:** Python
- **Data Processing:** pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Baseball Data:** Statcast, Baseball Savant, pybaseball
- **Player Development Technology:** Blast Motion, YakkerTech
- **Environment:** Google Colab, Jupyter Notebook

## Notes

These notebooks were developed for different analytical purposes over time and are not necessarily part of a single project.

Some tools require external datasets, additional Python packages, or modifications to file paths before running.
